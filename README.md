
# USPSTF Clinical Decision Support — Medical RAG Backend

Production-ready Retrieval-Augmented Generation (RAG) backend engine specialized in **US Preventive Services Task Force (USPSTF)** clinical guidelines. 

This repository contains the core AI retrieval, vector indexing, hybrid search, and grounded LLM generation layers designed for integration into web platforms and clinical interfaces.

---

## 🏗️ Architecture & Component Overview

* **Dense Vector Store:** ChromaDB with `BAAI/bge-small-en-v1.5` embeddings (via FastEmbed).
* **Sparse Lexical Engine:** BM25Okapi for medical keyword and acronym exact-matching.
* **Hybrid Fusion:** Reciprocal Rank Fusion (RRF, $\alpha=0.6$) combining dense semantic vectors and sparse BM25 scores.
* **Generation Engine:** Google Gemini (`gemini-3.6-flash`) running under strict clinical grounding prompts (`temperature=0.1`).
* **Clinical Safety Layer:** Pre-retrieval input guards, emergency disclaimers, and automated refusal for out-of-domain queries.

## 🔌 How to Integrate & Call the RAG Engine

The backend pipeline can be imported and executed in any Python web framework (FastAPI, Flask, Django):

```python
from src.retrieval.hybrid_retriever import MedicalHybridRetriever
from src.generation.generator import MedicalGenerator
from src.safety.medical_disclaimer import append_disclaimer

# 1. Initialize engines (Do this once on startup)
retriever = MedicalHybridRetriever(
    vector_store_dir="data/processed/chroma_db",
    chunks_json_path="data/processed/chunks.json",
    collection_name="uspstf_guidelines"
)
generator = MedicalGenerator()

# 2. Process clinical query
query = "What is the recommended daily dosage of folic acid to prevent neural tube defects?"

# 3. Retrieve Top-K Evidence Sources (alpha=0.6 recommended)
contexts = retriever.retrieve(query=query, top_k=3, alpha=0.6)

# 4. Generate Grounded Response with Citations
result = generator.generate_response(query=query, contexts=contexts)
final_response = append_disclaimer(result["answer"])

# 5. Output Payload Structure
# result["answer"]  -> Grounded clinical response with inline citations
# result["sources"] -> List of cited metadata (Document, Topic, Grade, Pages, Year)

```
